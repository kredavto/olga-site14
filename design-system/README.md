# Design System «Olga» — единая система на основе rep1–rep5

Система собрана из пяти референсов (`references/rep1–rep5.jpeg`). Ниже — сначала
разбор того, что у них общего, затем — что взято из каждого, затем — сама система.

---

## 1. Что общего у всех пяти референсов

### Типографика
Во всех пяти работает **одна и та же двухголосая пара**:
- **Крупный контрастный акцент** — заголовок-герой, который занимает 1/3 экрана
  и держит всю композицию (`Urban Elegance`, `Experience Luxury Living Outdoors`,
  `Heavenly Comfort`, `DESIGN FURNITURE`, `Featured`).
- **Тихий функциональный текст** — мелкий, ровный, часто в uppercase с широким
  трекингом (`HANDCRAFTED SINCE 1976`, `EXPLORE OUR NEW COLLECTIONS`, `MODERN CHAIR
  $249.00 USD`, названия категорий в rep2).

Общие свойства: **всего 2 гарнитуры на макет**, максимум 3–4 размера, крупный
скачок между H1 и остальным (соотношение ~4:1 — не плавная лестница, а «прыжок»),
насыщенность держится в пределах 300–700, курсив не используется.
Мелкий текст почти всегда идёт капслоком с трекингом +0.08–0.16em — это главный
приём «премиальности» во всех пяти.

### Сетка
Единый принцип — **центрированная ось + карточная лента под ней**:
- rep1: hero во всю ширину → горизонтальная лента карточек одинаковой ширины.
- rep2: 2 колонки карточек + вертикальный список строк.
- rep3/rep4: одна центральная колонка ~60–70% ширины, всё выключено по центру.
- rep5: центрированный hero → 3 равные колонки → 2 колонки (заголовок / текст).

То есть базово это **12-колоночная сетка**, но реально используются только три
раскладки: `12` (hero, full-bleed медиа), `4-4-4` (карточки товара), `6-6`
(заголовок слева / текст справа). Ничего асимметричнее в референсах нет.

### Палитра
Все пять построены одинаково: **~85% площади — один нейтральный фон**, ~10% —
тёмный «якорь» (текст, кнопка, футер), ~5% — один тёплый акцент. Реальные
доминанты, снятые с изображений:

| | фон | якорь | акцент |
|---|---|---|---|
| rep1 | `#E9E9E8` | `#211C1A` | `#9D5722` (дерево) |
| rep2 | `#F3F5F6` | `#232323` | `#AA5013` |
| rep3 | `#989F9D` / `#6F8D9D` | `#1F150F` | `#8C6D55` |
| rep4 | `#D9E5F1` | — | `#4476A7` |
| rep5 | `#EFEBEE` | `#352E2C` | `#8E621C` |

Ни в одном нет чистого белого `#FFF` и чистого чёрного `#000` — фон всегда чуть
тёплый или чуть голубой, «чёрный» всегда коричневатый. Насыщенных цветов нет
вообще: акцент — это цвет **материала** (дерево, охра, глина, терракота),
а не цвет интерфейса.

### Ритм блоков
Одинаковая партитура сверху вниз:
```
тонкая служебная полоса (нав / промо)  → 40–64px
ГЕРОЙ: фото на всю ширину + текст поверх → 60–90vh
пауза (чистый фон)                      → 80–120px
ЛЕНТА КАРТОЧЕК одинакового размера      → 3–6 штук в ряд
пауза
текстовый блок / CTA
```
Ритм — **чередование «шумно / тихо»**: плотный визуальный блок всегда окружён
пустотой сверху и снизу. Внутри блока элементы идут с одинаковым шагом
(в rep2 это буквально 16px между всеми строками карточек, в rep5 — 24px).

### Работа с пространством
- **Воздух вокруг заголовка больше, чем сам заголовок.** В rep3 и rep4 текст
  занимает верхнюю треть, остальные две трети отданы фотографии — текст «дышит».
- **Фотография — не иллюстрация, а фон.** В rep1, rep3, rep4, rep5 текст лежит
  прямо на снимке; изображение обрезано так, что в зоне текста остаётся спокойное
  однотонное поле (небо, стена, море).
- **Скругления крупные и мягкие**: 16–24px у карточек (rep1, rep2), pill у кнопок
  (rep1, rep2, rep3), а в rep5 — арка/эллипс у фото. Прямых углов почти нет.
- **Тени почти отсутствуют**, глубина создаётся не тенью, а сменой фона
  (светлая карточка на светло-сером поле — rep2).

## 3. Сама система

Файлы:
- `tokens.css` — все переменные (цвет, шрифт, размер, отступ, радиус, тень, движение)
- `tokens.json` — те же токены в JSON (для JS / Tailwind / Figma)
- `base.css` — сброс, типографика, сетка, утилиты
- `components.css` — кнопки, карточки, hero, лента, арка, анимируемый фон
- `index.html` — живое превью всей системы (откройте в браузере)

### Палитра

Нейтральная база (снята с rep3 и rep5):

| Токен | HEX | Назначение |
|---|---|---|
| `--c-ivory` | `#F6F3EF` | основной фон страницы |
| `--c-sand` | `#EFE9E1` | второй фон, чередование секций |
| `--c-clay` | `#DED3C6` | границы, плейсхолдеры фото |
| `--c-stone` | `#9A9490` | вторичный текст |
| `--c-espresso` | `#352E2C` | заголовки, тёмные секции, кнопка |
| `--c-ink` | `#1F1A18` | максимально тёмный текст |

Акценты:

| Токен | HEX | Назначение |
|---|---|---|
| `--c-ochre` | `#8E621C` | основной акцент (rep5), цена, активное состояние |
| `--c-terracotta` | `#AA5013` | вторичный акцент (rep2), бейдж, иконка |
| `--c-sea` | `#6F8D9D` | холодный баланс (rep3), ссылки в тёмной теме |
| `--c-sky-*` | `#D9E5F1 → #4476A7` | градиент анимируемого фона (rep4) |

Правило использования: **85 / 10 / 5** — нейтраль / тёмный якорь / акцент.
Акцент никогда не заливает площадь больше кнопки или бейджа.

### Типографика

- `--font-display`: **Playfair Display** (400/500/600) — высококонтрастная антиква
  из rep5/rep3. Только H1–H2, только `letter-spacing: -0.01em`, `line-height: 0.95–1.1`.
- `--font-ui`: **Jost** (300/400/500/600) — геометрический гротеск из rep1/rep2.
  Всё остальное: навигация, текст, кнопки, цены.
- `--font-mono-label`: тот же Jost, но `uppercase` + `letter-spacing: .14em`,
  размер 11–13px — это «подпись» из всех пяти референсов.

Шкала (крупный скачок H1 → остальное, как в референсах):

| Роль | clamp | LH | Трекинг |
|---|---|---|---|
| `--t-hero` | `clamp(3.5rem, 9vw, 8.5rem)` | 0.95 | −0.02em |
| `--t-h1` | `clamp(2.5rem, 5vw, 4.5rem)` | 1.05 | −0.01em |
| `--t-h2` | `clamp(1.75rem, 3vw, 2.75rem)` | 1.15 | −0.01em |
| `--t-h3` | `1.25rem` | 1.3 | 0 |
| `--t-body` | `1rem` (`--t-body-lg` `1.125rem`) | 1.65 | 0 |
| `--t-label` | `0.75rem` | 1.2 | +0.14em, uppercase |
| `--t-caption` | `0.8125rem` | 1.4 | +0.02em |

### Сетка

- Контейнер: `max-width 1440px`, поля `24px` (моб) / `48px` (планшет) / `80px` (десктоп).
- 12 колонок, gutter `24px`.
- Разрешённые раскладки — только три (как в референсах): `.g-12`, `.g-4-4-4`, `.g-6-6`.
- Брейкпоинты: `480 / 768 / 1024 / 1440`.

### Ритм и пространство

Шаг сетки — **8px**. Шкала отступов: `4, 8, 12, 16, 24, 32, 48, 64, 96, 128, 160`.

Вертикальный ритм секций (партитура из референсов):

| Секция | Высота / паддинг |
|---|---|
| Служебная полоса | `48px` |
| Hero | `min-height: 88vh`, текст в верхней трети |
| Пауза после hero | `96px` (моб) / `128px` (дес) |
| Секция контента | `padding: 96px 0` / `128px 0` |
| Между карточками | `24px` |
| Внутри карточки | `16px` |
| Футер | `padding: 96px 0 48px` |

Правило воздуха: **пустоты вокруг заголовка не меньше его кегля**. Строка текста
не шире `68ch`. Текст поверх фото ложится только на спокойную зону снимка, при
необходимости — через `--scrim` (мягкий градиент, не сплошная заливка).

### Форма

- Радиусы: `--r-sm 8px`, `--r-md 16px`, `--r-lg 24px`, `--r-pill 999px`,
  `--r-arch 50% 50% 0 0 / 38% 38% 0 0` (арка из rep5).
- Тени минимальны: `--sh-card 0 2px 12px rgba(31,26,24,.06)`,
  `--sh-lift 0 12px 32px rgba(31,26,24,.10)` — только на hover.

### Движение

- `--ease` `cubic-bezier(.22,.61,.36,1)`; длительности `--d-fast 180ms`,
  `--d-base 320ms`, `--d-slow 640ms`, `--d-amb 40s` (окружающая анимация фона).
- Анимируемый фон из rep4: `.bg-sky` — градиент неба + два слоя облаков,
  которые медленно плывут (`--d-amb`) и сдвигаются при скролле. Всё под
  `@media (prefers-reduced-motion: reduce)` останавливается.

### Компоненты

`.btn` (dark / ghost / pill), `.badge`, `.card` (фото 4:5 + название + цена),
`.rail` (горизонтальная лента карточек из rep1), `.arch` (фото-арка из rep5),
`.hero`, `.hero--dark`, `.section`, `.eyebrow` (капслок-подпись), `.marquee`
(промо-полоса из rep1), `.bg-sky` (анимируемый фон из rep4).

Полный визуальный справочник — `index.html`.
